# @drafteine/language-server

LSP server for the Drafteine file-tree language: diagnostics as you
type, completions with documentation, hover, formatting, document
symbols, folding, and quick fixes. One binary serves every LSP-capable
editor:

```sh
drafteine-language-server --stdio
```

See the repository's EDITORS.md for Neovim, Helix, Sublime, and Emacs
setup snippets. VS Code users should install the Drafteine extension,
which bundles this server.
